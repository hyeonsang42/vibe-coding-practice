## 먼저 봐야 할 발견 — 영업시간이 축제 시간과 어긋난다

찾아본 가게들의 영업 종료 시각이 **생각보다 이르다.**

| 가게 | 영업시간 | 저녁 축제 시간(18~21시)에 |
|---|---|---|
| 수복빵집 | 12:00~17:00 | ❌ **이미 닫힘** |
| 중앙국수 | 08:00~19:30 | △ 19:30 마감, 일요일 휴무 |
| 제일식당 | 10:30~19:30 | △ 19:30 마감 |

**이건 기획에 영향을 주는 사실이다.** 세 가지 중 하나를 골라야 한다.

1. **밤에 여는 가게 위주로 다시 찾는다** — 축제 기간 야간 연장 영업을 하는 곳이 있는지 현장 확인
2. **틈새 시간대를 저녁이 아닌 낮으로 잡는다** — 축제 낮 프로그램 사이의 공백으로 시나리오 변경
3. **"영업 중인 곳만 추천한다"는 규칙 자체를 발표 포인트로 삼는다** — 이미 구현되어 있다. 저녁 8시에 조회하면 낮 가게가 빠지는 걸 보여주면 오히려 설득력이 생긴다

→ **3번이 가장 현실적이고, 이미 만들어져 있다.** 다만 그러려면 밤에 여는 가게가 최소 3~4곳은 있어야 코스가 만들어진다. 현장 조사 때 **야간 영업 여부**를 반드시 확인할 것.

## 현장에서 채울 빈칸

각 가게마다 아래를 채우면 그대로 코드로 옮길 수 있다.

```
상호명        :
분류          : 간식 / 기념품 / 카페 / 시장 / 문화공간
주소          :
위도, 경도    :            ← 카카오맵에서 좌표 복사 (지도 표시에 필요)
축제장 도보   :        분   ← 지도 앱 도보 경로로 측정
평균 체류     :        분   ← 관찰 또는 추정
1인 예상 지출 :        원
영업시간      :   :   ~   :
야간 연장     : 축제 기간에 늦게까지 여는가?
실내 여부     : 실내 / 실외
혜택          : (상점 동의 전에는 비워둘 것)
한 줄 소개    :
```

## 혜택 항목 주의

**상점주 동의 없이 실제 상호명 + 혜택을 화면에 띄우지 않는다.** 실제 가게가 그 혜택을 준다고 공표하는 셈이 된다. 동의를 못 받았으면 화면에 "협의 예정"으로 표시한다.
